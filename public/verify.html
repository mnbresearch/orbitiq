Check a document

The window and threshold are printed on the document. A report over a different period is legitimately a different digest, so match those first before drawing any conclusion.
What a match establishes. That the rows the document describes are the rows the archive holds, and that the hash chain over them reconciles — so they have not been altered since they were written.
What it does not establish. That any decision was correct, that the screening was complete, or that nothing happened where no row appears: an action taken outside this system leaves no trace in it. Probabilities come from public element sets, which carry no covariance; the covariance is modelled and every row states which model produced it.
Scope of the guarantee. Tamper-evident, not tamper-proof, with GitHub acting as the notary via hourly witness runs. It shows a hash was publicly observable at a time. It is not a signature and does not attest authorship.

OrbitIQ API

REST + WebSocket API for space traffic intelligence. Base path /api/v1 (alias /api). No key needed for read endpoints; workspace endpoints use X-API-Key.

Quick start

curl {host}/api/v1/satellites?org=spacex&limit=5
curl -X POST {host}/api/v1/workspaces -H "Content-Type: application/json" \
  -d '{"name":"ACME Space Ops","org":"spacex"}'
# → returns your apiKey (shown once)
curl {host}/api/v1/alerts -H "X-API-Key: oiq_…"

Catalog & tracking

GET/satellites
Full catalog with GP orbital elements. Params: org, q (name/NORAD), limit.
GET/organizations
Operators detected in the catalog, with object counts.
GET/stats
Totals by type and orbital regime.
GET/recent-objects
Newest payloads on orbit by international designator.
GET/decay-watch
Lowest-perigee objects (re-entry candidates).
GET/maneuvers
Maneuvers detected from epoch-over-epoch element changes.

Screening & safety

GET/conjunctions
Close-approach screening. Params: org (primaries), hours (≤12), thresholdKm (≤50). Results cached 15 min.
GET/passes
48 h ground passes. Params: satId, lat, lon.

Analytics & traffic

GET/analytics
Histograms (altitude, inclination), launch-year trend, per-org counts, daily population snapshots.
GET/traffic/congestion
LEO shell occupancy in 25 km bins with load tiers and dominant operator per shell.

Mission design

GET/tools/transfer
Hohmann transfer with combined plane change. Params: alt1, alt2 (km), planeChange (°).
GET/tools/launch-plan
Launch-site feasibility, azimuths, first-order Δv. Params: incl (°), alt (km).

Workspaces (multi-tenant)

POST/workspaces
Create a workspace bound to an operator. Body: {name, org}. Returns the API key once.
GET/workspaceX-API-Key
Workspace profile + daily usage metering.
PUT/workspaceX-API-Key
Update webhook, org, or screening {hours, thresholdKm}.
POST/workspace/scanX-API-Key
Run the workspace's conjunction scan now. New events become alerts, push over WebSocket, and POST to the webhook.
GET/alertsX-API-Key
Alert inbox (deduplicated conjunction events).
POST/alerts/readX-API-Key
Mark all alerts read.

Intel Pack plan-gated

GET/plans
Subscription tiers, quotas and inclusions. Public.
GET/intel/staleness · /intel/gabbard
Free teasers: element-age distribution, breakup Gabbard series.
GET/intel/eclipse · /intel/passes-proTracker
Eclipse windows; pro passes with Doppler shift and optical visibility. Params: satId, observer lat/lon, freqMhz.
GET/intel/conjunctions · /intel/fleet-risk · /intel/launch-correlation · /intel/anomaliesOperator
Pc-augmented screening, Fleet Risk Index with component breakdown, launch-object correlation, pattern-of-life anomaly flags.

Detection archive the data moat

GET/archive/stats
Archive size and event counts by type. Public — watch it grow.
GET/archive/eventsOperator
Query archived detections. Params: type (conjunction, maneuver, anomaly, risk, reentry, environment, congestion), org, since, until, limit.
GET/archive/risk-historyOperator
Fleet Risk Index time series for an org.
GET/archive/reportOperator
Weekly Fleet Intelligence report (JSON + markdown).
POST/reports/shareOperator
Mint a public, branded, live report link at /r/{token} — safe to forward to execs and insurers.

Environment & network ops (v7)

GET/spaceweather
Live NOAA SWPC Kp index, storm scale, F10.7 flux, drag advisory, aurora boundary. Public.
GET/reentry
Re-entry board with lifetime projections and debris-band latitudes. Public teaser (top 12); full board with a Tracker key.
GET/network/stations
The 10-station global ground network. Public.
GET/network/contact-planTracker
Multi-station contact schedule: passes, total contact time, coverage %, longest blackout. Params: satId, hours (≤48), minEl.

Exports

GET/export/catalog.csv
Catalog as CSV. Param: org.
GET/export/conjunctions.csv
Screening results as CSV. Params as /conjunctions.
GET/export/fleet.csvOperator
Fleet CSV annotated with perigee/apogee and lifetime projections.
GET/export/ledger.csvOperator
The detection archive as CSV — audit-ready, timestamped at detection.

WebSocket

WS/ws
Live push. Messages: {type:"hello"} on connect, {type:"alerts", payload:{workspaceId, count, top[]}} when background scans find new events.

Data honesty

Positions derive from public GP elements (km-level uncertainty). Suitable for monitoring, screening and triage — not operational collision avoidance. Sources: CelesTrak, The Space Devs. Background scans run every 30 minutes.
